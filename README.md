# 🎧 TuneFetch

 A modern full-stack web app to convert YouTube videos into high-quality MP3 files with live preview.

🌐 **Live Demo:** https://tune-fetch-beta.vercel.app/

---

## ✨ Features

- 🎥 Paste any YouTube URL
- 🖼️ Auto fetch thumbnail + title
- 🎧 Preview audio before download
- ⬇️ Download MP3 instantly
- ⚡ Fast conversion using yt-dlp + ffmpeg
- 💎 Premium UI (Tailwind + Glassmorphism)

---

## 🧑‍💻 Tech Stack ⚙️

### Frontend
- React (Vite)
- Tailwind CSS v4
- Axios

### Backend
- Node.js
- Express.js
- yt-dlp (YouTube extraction)
- FFmpeg (audio conversion)
